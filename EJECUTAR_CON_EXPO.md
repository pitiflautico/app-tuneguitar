# 🚀 Ejecutar Guitar Tuna con Expo

## ✅ El proyecto ya está listo para Expo!

---

## 📱 Paso 1: Inicia el servidor

```bash
cd /home/user/app-tuneguitar
npx expo start
```

## 📱 Paso 2: Descarga Expo Go en tu teléfono

- **Android**: [Play Store - Expo Go](https://play.google.com/store/apps/details?id=host.exp.exponent)
- **iPhone**: [App Store - Expo Go](https://apps.apple.com/app/expo-go/id982107779)

## 📱 Paso 3: Escanea el QR

Verás un código QR en la terminal:

```
Starting project at /home/user/app-tuneguitar

› Metro waiting on http://localhost:8081
› Scan the QR code above

█▀▀▀▀▀█ ▀ ▄█  █▀▀▀▀▀█
█ ███ █ ▄ ▀█  █ ███ █
█ ▀▀▀ █ █ █▀  █ ▀▀▀ █
▀▀▀▀▀▀▀ ▀ ▀ ▀ ▀▀▀▀▀▀▀

› Press a │ open Android
› Press i │ open iOS
```

**Escanea con:**
- Android: Abre Expo Go → "Scan QR Code"
- iPhone: Abre Cámara → Apunta al QR

## 🎉 ¡Listo!

La app se abrirá en tu teléfono en unos segundos.

## 📝 Notas

Esta versión está configurada en **modo demo** para funcionar con Expo:

✅ **Funciona:**
- Todas las pantallas y navegación
- UI completa con 3 temas
- Animaciones suaves
- Almacenamiento local
- Todos los controles e interacciones

⚠️ **En modo simulación:**
- Detección de pitch (muestra datos aleatorios)
- Audio (muestra logs en consola)
- Ads (muestra banners de demo)

Para funcionalidad completa de audio, usa el proyecto con Android Studio.
